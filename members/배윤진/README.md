## How I study

Each week gets one folder, `weekN/`, with three sections.

> **주차 번호 주의:** `weekN` = **N주차 숙제** = **N+1주차 미팅 주제**.
> 레포 README의 계획표는 미팅 기준이라 한 칸 어긋나 보이는 게 정상.

| Section | 내용 |
| --- | --- |
| **A** `A_docs/` | IBM 공식 가이드 원본을 그대로 두고, 직접 실행하며 새 셀로만 메모 |
| **B** `B_practice/` | Advocate practice exam에서 해당 토픽 문제만 추출해 풀이 + 오답 정리. 출처: [clausia](https://github.com/clausia/qiskit-v2.x-cert-practice-exam) / [Q-Bees](https://github.com/Q-Bees/Qiskit-v2.X-Certification-Practice-Questions) / [algovista](https://github.com/algovista-collab/qiskit_v2_study_materials) / [MarcoBarroca](https://github.com/MarcoBarroca/qiskit-v2-mock-exam) |
| **C** `C_quiz/` | 문제 노트북. 정답은 접어두고, 출력 맞히기 답은 실제 실행으로 확정 |

메모 표기 (GitHub에서도 보이도록 색 대신 인용문 사용):

```markdown
> **📝 내 메모** — compose는 적용 순서가 반대. dot이랑 헷갈리지 말 것.
```

**환경:** conda env `qiskit-sg24` (Python 3.12, qiskit 2.5.2). 노트북 커널은 `Python (qiskit-sg24)`.
